# Pit Happens

Brawler medieval para 8 guerreros sobre una isla flotante que se desmorona.
Elige uno de 4 héroes, rompe el suelo con tu habilidad y tira a todos al vacío.

**Jugar:** https://apuestasjoseenci-png.github.io/pit-happens/

- **Solo:** tú contra 7 bots.
- **Online:** partida pública con quien esté conectado (los bots llenan los huecos a los 30 s),
  o sala privada con un código para tus amigos. Si nadie jugaba hace rato, el servidor tarda
  hasta un minuto en despertar.

Controles: WASD/flechas mover · J o Espacio atacar · K habilidad · L esquivar · P pausa · M sonido.
En el móvil: joystick a la izquierda, botones a la derecha.
