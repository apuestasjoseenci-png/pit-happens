# Suelo Roto

Brawler medieval para 8 jugadores (tú contra 7 bots) sobre una isla flotante que se desmorona.
Elige uno de 4 héroes, rompe el suelo con tu habilidad y sé el último en pie.

**Jugar:** https://apuestasjoseenci-png.github.io/suelo-roto/

Controles: WASD/flechas mover · J o Espacio atacar · K habilidad · L esquivar · P pausa · M sonido.
En el móvil: joystick a la izquierda, botones a la derecha.
